# Sample Garment Catalogue

`sample-products.json` provides eight sample garments for the product catalogue: two shirts, two jackets, two pairs of trousers, and two dresses. Each record includes an identifier, name, category, short description, and garment specifications to support later product-card and information-panel work.

The image fields are intentionally empty until the matching product artwork is added to `Assets/Member3/Images`. The catalogue is data-only; the reusable C# product model and runtime loading are planned for later commits.

The sample products are illustrative project data, not specifications for real retail products.
